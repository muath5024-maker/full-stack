# 🏭 Kimi Agent Website: The Software Commerce Platform
# منصة التجارة بالبرمجيات والمصنع الذكي

## 🌟 الرؤية (The Vision)
هذا المشروع ليس مجرد أداة لبناء المواقع، بل هو **منصة تجارة برمجيات (Software Commerce Platform)** متكاملة، تهدف إلى أتمتة دورة حياة البرمجيات بالكامل: من الفكرة، إلى التصميم، فالتطوير، ثم البيع، وأخيراً التشغيل والإدارة.

النظام يجمع بين:
1.  **سوق رقمي (Marketplace):** متعدد البائعين لبيع المنتجات الرقمية.
2.  **مصنع ذكي (AI Factory):** لتوليد التطبيقات والمواقع أوتوماتيكياً.
3.  **استوديو إبداعي (GenAI Studio):** لتحرير وتوليد المحتوى (نصوص، صور، كود).
4.  **نظام إدارة موارد (ERP/CRM):** لوحات تحكم للملاك، البائعين، والموظفين.

---

## 🏗️ الهيكلية العامة (High-Level Architecture)

المشروع مبني بالكامل على **Next.js 15** مع **App Router**:

*   **الواجهة (Frontend):** Server Components + Client Components لتجربة مستخدم سريعة وتفاعلية.
*   **الخادم (API):** Next.js API Routes لمعالجة الطلبات والتواصل مع الخدمات الخارجية.
*   **البيانات (Data):** Supabase (PostgreSQL) لقاعدة البيانات والمصادقة.
*   **التصميم (UI):** Tailwind CSS + shadcn/ui + GSAP للحركة.

---

## 🚀 التبويبات والموديولات الرئيسية

1.  **المتجر (Store):** واجهة التجارة الإلكترونية للمنتجات الرقمية.
2.  **الاستوديو (Studio):** أدوات الذكاء الاصطناعي للتوليد والتحرير.
3.  **البناء والتطوير (Builder):** المعالج الذكي لبناء المشاريع الجديدة (SaaS Factory).
4.  **لوحات التحكم (Dashboards):**
    *   **Admin:** للإدارة العليا والمالك.
    *   **Vendor:** للبائعين المستقلين.
    *   **Employee:** للموظفين وفرق العمل.

# بناء الإنتاج
npm run build
npm start
