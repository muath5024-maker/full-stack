# 📦 Mbuy Ecosystem Modules
# مكونات النظام البيئي لمنصة التجارة بالبرمجيات

هذا المستند يحدد الموديولات الـ 13 الرئيسية المكونة للمشروع، والتي تعمل بتناغم لتكوين المنصة المتكاملة.

## 1. متاجر إلكترونية (E-commerce Stores)
*   **الوصف:** سوق رقمي متعدد البائعين (Multi-vendor Marketplace).
*   **الوظيفة:** يسمح للمطورين والمصممين ببيع القوالب، الإضافات، والبرمجيات الجاهزة.
*   **المميزات:** عربة تسوق، تقييمات، صفحات بائعين، تصنيفات.

## 2. لوحات تحكم (Control Panels)
*   **الوصف:** مراكز القيادة للنظام بأكمله.
*   **الأنواع:**
    *   **لوحة المالك (Super Admin):** تحكم كامل في المنصة والعمولات.
    *   **لوحة البائع (Vendor):** إدارة المنتجات والمبيعات.
    *   **لوحة الموظف (Employee):** للدعم الفني، إدارة الجودة، والمبيعات.
    *   **لوحة العميل (Customer):** إدارة المشتريات والمشاريع.

## 3. البناء والتطوير (Build & Develop - SaaS Factory)
*   **الوصف:** المحرك الذكي لبناء البرمجيات (The Engine).
*   **الوظيفة:** معالج (Wizard) يأخذ متطلبات العميل ويحولها إلى تطبيق كامل.
*   **المخرجات:** كود مصدري (Source Code)، مستودع GitHub، تطبيق منشور (Deploy).

## 4. المنتجات (Products)
*   **الوصف:** نظام إدارة الأصول الرقمية.
*   **الأنواع:** قوالب (Templates)، مكونات (Components)، خدمات (Services)، اشتراكات (SaaS).
*   **الخصائص:** إصدارات، تراخيص، ملفات تحميل.

## 5. الاستديو (Studio)
*   **الوصف:** مجموعة أدوات الذكاء الاصطناعي الإبداعية (GenAI Tools).
*   **المكونات:**
    *   مولد النصوص (Copywriting).
    *   مولد الصور (Image Gen).
    *   محرر الكود (Code Editor).
    *   محرر الفيديو (Video Editor - مستقبلاً).

## 6. التسويق والمبيعات (Marketing & Sales)
*   **الوصف:** أدوات لترويج المنتجات وزيادة المبيعات.
*   **المميزات:** أكواد خصم، حملات بريدية، تحسين محركات البحث (SEO)، نظام العمولة (Affiliate).

## 7. الأتمتة (Automation)
*   **الوصف:** المحرك الخلفي لإدارة العمليات المتكررة.
*   **الوظيفة:** تشغيل الـ Workers، جدولة المهام، ربط الخدمات ببعضها (Integrations).

## 8. دليل المنصة (Platform Guide)
*   **الوصف:** قاعدة المعرفة والتوثيق (Knowledge Base).
*   **المحتوى:** شروحات فيديو، مقالات تعليمية، توثيق API للمطورين.

## 9. الباك اند (Backend)
*   **الوصف:** العقل المدبر للنظام (The Brain).
*   **التقنية:** FastAPI (Python).
*   **المسؤوليات:** المصادقة، التوجيه، الأمان، ومنطق الأعمال المركزي.

## 10. الإعدادات (Settings)
*   **الوصف:** مركز التحكم في تكوين النظام.
*   **المحتوى:** إعدادات الدفع، إعدادات المناطق، اللغات، والضرائب.

## 11. قواعد البيانات (Databases)
*   **الوصف:** الذاكرة المركزية للنظام.
*   **التقنية:** PostgreSQL (Supabase).
*   **الهيكل:** مخطط علائقي ضخم (Massive Relational Schema) موحد لجميع الموديولات.

## 12. Docker (Containerization)
*   **الوصف:** البنية التحتية لتشغيل النظام.
*   **الوظيفة:** ضمان عمل "المصنع" في أي بيئة (Local, Cloud) بنفس الكفاءة.

## 13. الواجهات (Interfaces - UI)
*   **الوصف:** الطبقة المرئية التي يتفاعل معها المستخدم.
*   **التقنية:** React 19 + Tailwind CSS.
*   **المبدأ:** واجهة موحدة (Unified UI) تخدم جميع المستخدمين مع اختلاف الصلاحيات.
